## 변경 기록 방법

- 공통 컴포넌트 승격 또는 API 변경 시 즉시 갱신
- 사용자에게 보이는 변화가 있으면 적용 전 확인
- `적용 대기`는 기술 부채이며 디자인 예외로 취급하지 않음
- `디자인 예외`에는 코드와 페이지 README에 이유와 재검토 조건 기록
