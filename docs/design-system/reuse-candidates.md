# 공통화 후보 목록

개발 중 발견한 유사 구현을 메모만 해두고, 실제 비교와 결정은 페이지 완료 시 진행합니다.

## 기록 규칙

- 개발 중에는 작업을 멈추거나 즉시 리팩터링하지 않습니다.
- 같은 역할의 두 번째 구현부터 후보로 기록합니다.
- 세 번째 등장 시 다음 페이지 완료 검토의 필수 결정 대상으로 표시합니다.
- 결정 후에는 이 목록에서 제거하고 `component-adoption.md` 또는 디자인 예외 기록으로 옮깁니다.

## 후보

| 후보 | 발견 페이지 | 공통으로 보이는 부분 | 현재 차이 | 등장 횟수 | 검토 예정 | 상태 |
| --- | --- | --- | --- | ---: | --- | --- |
| 없음 | - | - | - | 0 | - | 대기 |

## 가능한 결정

- 전체 공통화
- 공통 컴포넌트 + variant
- 공통 뼈대 + 페이지별 조립
- 로직만 공유
- 디자인 토큰만 공유
- 별도 유지
