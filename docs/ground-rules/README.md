# Ground Rules

이 폴더는 `Portfolio-React` 프로젝트의 장기 운영 규칙을 보관합니다. React 소스 코드와 분리하여, 개발을 시작하기 전에 팀과 도구가 동일한 기준을 확인할 수 있게 합니다.

## 문서 구성

| 파일 | 역할 |
| --- | --- |
| `01-repository-and-branching.md` | 저장소, 브랜치, 병합 기준 |
| `02-directory-structure.md` | React 프로젝트 폴더 배치 기준 |
| `03-naming-conventions.md` | 폴더, 파일, 컴포넌트 및 에셋 이름 규칙 |
| `04-backup-and-release.md` | 백업, 태그, 릴리스 및 복구 기준 |
| `05-development-workflow.md` | 로컬 작업부터 배포까지의 순서 |
| `06-code-organization-and-comments.md` | 섹션 위계, 주석, 디자인 예외 및 기획·개발 소통 기준 |

## 이 폴더의 파일 관리 규칙

- 문서 파일은 읽는 순서대로 두 자리 숫자 접두사를 사용합니다: `01-`, `02-`, `03-`.
- 문서 파일명은 영문 소문자 `kebab-case`를 사용합니다.
- 하나의 문서는 하나의 주제만 다룹니다.
- 규칙을 변경할 때는 관련 문서와 루트 `README.md`의 링크를 함께 확인합니다.
- 현재 규칙과 폐기된 규칙을 한 문서에 섞지 않습니다. 중요한 변경은 Git 기록과 릴리스 태그로 보존합니다.

## 우선순위

규칙끼리 충돌하면 다음 순서로 판단합니다.

1. 사용자 데이터와 기존 운영 사이트 보호
2. `main` 브랜치의 안정성
3. 화면과 기능의 회귀 방지
4. 재사용성과 일관성
5. 기획자와 개발자 사이의 이해 가능성
6. 개발 편의성
