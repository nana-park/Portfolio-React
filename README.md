# Portfolio React

기존 HTML 포트폴리오를 React로 재구축하는 프로젝트입니다.

- 기존 HTML 원본: [`nana-park/Portfolio`](https://github.com/nana-park/Portfolio)
- React 프로젝트: [`nana-park/Portfolio-React`](https://github.com/nana-park/Portfolio-React)
- 운영 원칙: 기존 HTML 저장소는 보존하고, React 작업은 이 저장소에서만 진행합니다.
